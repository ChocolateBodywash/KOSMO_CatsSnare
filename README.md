## KOSMO Format Cats Snare
### An 808 Style Snare

![](/IMG/Cats.jpg)

A KOSMO format module of a 808 Style Snare

I wanted a 808 style snare, but I also wanted it to be as simple as possible (no accent, pitch cv, etc) so I blended two simple schematics together. 

I used the tone section from the N8 808 Snare:
https://www.n8synth.co.uk/diy-eurorack/eurorack-808-snare

And the Noise section from Mortiz Kleins 808 Style Snare:
https://www.youtube.com/watch?v=hULEn2_4Unw

I like how the N8 tone blends two tone generators, it's pretty close to the original 808 schematic.
The noise from the Mortiz klein design I find to be simple, punchy and awesome.

I'm not 100% sure if I mixed the two properly, but I think the result is good enough for me.
